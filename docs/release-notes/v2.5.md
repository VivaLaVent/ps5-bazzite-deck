## What's new

**v2.5 is the stable version.** **PS5 Bazzite Deck is a bootc image now, and that is the way to run it.** Still on an older Legacy install? Switching is recommended, see bootc below. Not sure which one you run? `ps5-report` shows it on its Install line.

Everything since v1.8.9:

### Newer kernel

Linux 7.3.1 with rmux's current PS5 patches: newer Bluetooth support for the IW620 (original PS5) and MediaTek (Slim, Pro) chips, PS5 Pro CPU and GPU clock control, and the fan driver. The display handling is the proven one from v1.8.9: 1080p, 1440p and 4K at 60 and 120 Hz, 4K120 over HDMI 2.1 on FLAVA3 consoles where the TV supports it, VRR on FLAVA3 for displays with HDMI VRR, the picture coming back after the TV wakes or switches input, and the fixes for TVs that fall back to HDMI 1.4. The 100 Hz modes are gone; they caused picture artifacts on Verde consoles.

### Controller and Bluetooth

- A DualSense keeps its pairing after a cold boot (the Linux-only Bluetooth address is saved instead of derived anew at every start).
- PS5 Pro: Bluetooth works from a cold boot, and the Linux-only address works there too.
- Original PS5: Bluetooth finds new devices again, and the Bluetooth and Wi-Fi scripts are the ones that ran most reliably (v2.1.1).

### PS5 Pro

- The Pro's GPU firmware loads on every install, and D3D9 games work.
- 1 GB VRAM and an 80 °C GPU limit by default, set once; your own changes stay.
- A GPU clock governor with a temperature limit, the fan driver starting on the Pro, and GPU load in MangoHud and the Steam overlay.

### Fan and power

- The console's own fan control stays the default; the kernel's fan curve is optional. No spike to full speed at shutdown or reboot, and the fan target is kept after sleep.
- CPU boost off is really off.

### Updates and reports

- Updating installs a new kernel next to the running one, which stays as the backup, and prints an undo command.
- `ps5-report` starts with a summary of your console (model, HDMI chip, wireless chip, install type, display, Bluetooth and Wi-Fi state) and collects everything a bug report needs.

## bootc

PS5 Bazzite Deck is a bootc image: the whole system is one image, built and checked as a unit by GitHub Actions, the way Bazzite itself is made.

- **Every console runs the same system.** The PS5 kernel, drivers and fixes are part of the image, not files changed on your drive.
- **Updates download in the background** and take over at the next start. A power cut during an update doesn't leave a half-installed system.
- **The previous version stays on the drive.** `sudo bootc rollback` and a restart take you back.
- **Games, settings and your files are kept** across updates and rollbacks.

It starts with **bazzite-bootc-loader** from this release: the official Linux loader built from its `main` branch, plus support for the boot entries bootc uses to choose and roll back versions.

### New install, or switching from Legacy

Switching means flashing the bootc image, which erases the drive: use a second drive, or copy off what you want to keep first. You need a USB drive or SSD of 64 GB or more.

1. Extract `ps5-bazzite-deck-bootc-v2.5.img.7z.001` with 7-Zip.
2. Flash the `.img`: on Windows with [Rufus](https://rufus.ie) in **DD Image mode** (balenaEtcher has produced drives that don't boot); on Linux or macOS with `sudo dd if=ps5-bazzite-deck-bootc-v2.5.img of=/dev/sdX bs=4M status=progress` (replace `/dev/sdX` with your drive).
3. Start it with `bazzite-bootc-loader-v2.5.elf`.

On the first start, Steam downloads and updates itself before Game Mode appears. That can take 10 to 15 minutes on a black screen; leave it running.

### Updating

Steam's update button (**Settings → System**) or `sudo bootc upgrade` in a terminal. On a v2.4 test version, switch to the stable channel once first: `sudo bootc switch ghcr.io/vivalavent/ps5-bazzite-bootc:stable`. After an update, restart and start with the loader.

## Problems

- `sudo bootc rollback`, then restart.
- On a Legacy install: the undo command the update prints, or go back to [v1.8.9](https://github.com/VivaLaVent/ps5-bazzite-deck/releases/tag/v1.8.9) with the update command and `v1.8.9`.
- Either way, report it in Discord with the file `ps5-report` saves.

## Sharing logs

```
bash <(curl -fsSL https://raw.githubusercontent.com/VivaLaVent/ps5-bazzite-deck/main/tools/ps5-report.sh)
```
Paste its `SUMMARY` line when you report results, and attach the saved file for a bug report.

## Legacy

Installs from before v2.5 run the older Legacy form and update in place:
```
bash <(curl -fsSL https://raw.githubusercontent.com/VivaLaVent/ps5-bazzite-deck/main/tools/update-latest.sh) v2.5
```
Then power off and start with the loader. Switching to bootc is recommended (see bootc above).
