## What's new

Everything since [v2.13](https://github.com/VivaLaVent/ps5-bazzite-deck/releases/tag/v2.13), the last Stable.

### Fixed

- **A GPU hang no longer freezes the display.** The game may still close. From the official PS5 kernel.
- **Game Mode starts again after a crash.** When gamescope crashed and Steam hung, the screen stayed on a text console until a forced shutdown.
- **The console's Bluetooth no longer shuts down after a burst of USB activity** until a restart. From the official PS5 kernel.
- **Original PS5 Wi-Fi:** the console no longer freezes when the Wi-Fi chip stops answering (two places in the driver could wait forever; the second was found by PS5-CachyOS), and Wi-Fi no longer follows the access point's country (your own network went missing).
- **1440p at 100 and 120 Hz** was shifted up on the FLAVA3 HDMI chip.
- **PS5 Pro:** the GPU slows down at 85 °C instead of 80 °C, which matched the fan's target and held the GPU back.
- **Bazzite's performance profile starts the LAVD scheduler:** the kernel is built with pahole 1.31.
- **Emergency mode gives a shell** instead of "the root account is locked".
- **A quiet start:** kernel messages no longer fill the screen at boot or when Game Mode closes.

### New

- **Native resolution at the first start** (4K, 1440p or 1080p, at 60 Hz) instead of 1080p60. A resolution you chose stays. If the screen stays dark: `amdgpu.force_1080p=1` in `cmdline.txt` on the boot partition.
- **Drivers for controllers, wheels and streaming:** the Xbox Wireless Adapter, Xbox controllers over Bluetooth, Logitech, Thrustmaster and Fanatec wheels with force feedback, the GameCube adapter, the OBS virtual camera and Razer devices.
- **One DualSense pairing for the PS5 and Linux on the original PS5 and Slim:** pair in the PS5 OS; Linux imports it at every start. The Pro keeps its own Linux address, because the shared pairing doesn't connect there yet.
- **PS5 Pro:** 60 compute units on system software 13.00, with this release's loader.
- **Linux 7.3.5** (was 7.3.3), with the stable updates' Bluetooth and USB fixes.
- **Graphics driver from Mesa 26.2.7,** as Bazzite, on the PS5 Pro and for 32-bit programs. On the original PS5 and Slim, DirectMesh (below) is the driver; it is built on Mesa 26.2.1.
- **Steam's Wi-Fi power setting is respected:** Wi-Fi power saving stays off by default, but the setting is no longer forced back every two minutes.
- **The Linux-only Bluetooth address is for the PS5 Pro only.** If you switched it on, on an original PS5 or a Slim: it's gone; pair the controller in the PS5 OS, Linux shares that pairing.
- **Legacy installs** (from before v2.5) are no longer supported: flash a new install, or use the [converter from v2.16.2](https://wiki.ps5-linux.eu/updating/legacy).

### On by default, with an off switch

- **Mesh shaders on the original PS5 and Slim.** DirectMesh, the driver with Mesh shaders, is the Vulkan driver of the whole session: Game Mode, Steam and games. Off: `ps5-directmesh off`, then restart. One game on the standard driver: `ps5-directmesh --system %command%` as its launch option. DirectMesh keeps the compute queue open, so `AMD_PS5_COMPUTE_QUEUE=0` only works together with `--system`. Flatpak apps keep their own driver.
- **VERDE consoles: HDR and 4K at 100/120 Hz.** HDR goes out as 12-bit YCbCr 4:2:2, 4K at 120 Hz over HDMI 2.1 FRL. If colours are wrong: `sudo rpm-ostree kargs --append=hdmi.verde_infoframes=0 --append=hdmi.verde_deep_colour=0 --append=hdmi.verde_frl=0`, then start with the loader. If the console doesn't start: on a PC, add ` hdmi.verde_infoframes=0 hdmi.verde_deep_colour=0 hdmi.verde_frl=0` to the end of the line in `cmdline.txt` on the drive's boot partition.
- **PS5 Pro: CPU boost to 3.5 GHz.** It adds heat. Off: `ps5-perf pro-boost off`.

### Option

- **A game that drops out of Game Mode** with `Failed to pin framebuffer`: Game Mode → Settings → System → Enable Developer Mode, then Developer → **Force Composite**. Rift Apart starts with it.

## What to test

- After a game crashes in Game Mode: does Game Mode come back by itself?
- VRR and HDR together (FLAVA3): still as before? Linux 7.3.5 changed how the VRR packet is marked in HDR.
- Original PS5: does a DualSense paired in the PS5 OS connect in Linux without pairing?
- VERDE consoles: does the console start every time, does HDR switch on, does 4K at 120 Hz come up? The TV model helps.
- Original PS5 and Slim: do your games run as before on DirectMesh? If one doesn't, try it with `ps5-directmesh --system %command%` and report both. Does a 32-bit game still start (they keep the standard driver)?
- Wi-Fi drops: power saving is no longer forced off every two minutes, as in Bazzite itself. At the moment of a drop, in Game Mode: `iw dev wlp64s0f7 get power_save`.
- PS5 Pro: the SoC temperature on the Fan line of `ps5-report` after 15 minutes of a game, with the boost on.

## bootc

### New install

A USB drive or SSD of 64 GB or more; flashing erases it.

1. Extract `ps5-bazzite-deck-bootc-v3.0.img.7z.001` with [7-Zip](https://www.7-zip.org). The first line of `ps5-bazzite-deck-bootc-v3.0.img.sha256` is the image's SHA-256.
2. Flash the `.img` with [balenaEtcher](https://etcher.balena.io), not Rufus. If Windows offers to format the drive, choose **Cancel**.
3. Start it with `bazzite-bootc-loader-v3.0.elf`. The first start takes a few minutes.

### Switching from Legacy

Flash a new install, or convert in place with the converter from v2.16.2, keeping users, games and Flatpaks: [wiki](https://wiki.ps5-linux.eu/updating/legacy).

### Updating

`sudo bootc upgrade`, or Steam's update button. It applies at the next start with the loader. Use `bazzite-bootc-loader-v3.0.elf` from this release: a PS5 Pro on system software 13.00 needs it for its GPU.

Stable follows the release marked **Latest**, Beta the newest pre-release: `sudo bootc switch ghcr.io/vivalavent/ps5-bazzite-bootc:beta` (or `:stable`), or Steam → Settings → System → OS Update Channel.

## Problems

- `sudo bootc rollback`, then restart with the loader.
- It doesn't start at all: follow `ROLLBACK.txt` on the drive's boot partition.
- Report it on Discord with the file `ps5-report` saves.

## Known issues

- PS5 Pro: a DualSense paired in the PS5 OS doesn't connect in Linux ([#73](https://github.com/VivaLaVent/ps5-bazzite-deck/issues/73)); the Pro keeps its own Linux Bluetooth address, pair once in Game Mode.
- DualSense over Bluetooth, late or ghost inputs in a Proton game: Bazzite Portal → Troubleshoot → switch InputPlumber off.
- Some games drop out of Game Mode with `Failed to pin framebuffer` when VRAM is full: Rift Apart runs with Steam's Force Composite (see Option in What's new); Returnal, Avowed and Spider-Man: Miles Morales still need Desktop Mode.
- VERDE HDMI chip: no VRR yet.
- The clock is wrong for the first minute after a start, until network time arrives.
- Starting without the USB drive is experimental: [wiki](https://wiki.ps5-linux.eu/installation/m2-bazzite-deck#usb-free).
- M.2 installs from v2.11 or older can stop in an emergency shell after an update: [fix](https://wiki.ps5-linux.eu/troubleshooting/error-messages#ostree-boot-counter).
- A drive flashed before v2.11 doesn't start on PS5 system software 4.x: [fix](https://wiki.ps5-linux.eu/troubleshooting/error-messages#gpt-first-lba).
