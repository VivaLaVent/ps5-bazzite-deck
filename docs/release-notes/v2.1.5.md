## What's new
- **PS5 Pro: D3D9 games play past the first 3D frame.** A GPU hang (ring timeout at a draw call) happened with DXVK D3D9 titles (Fable Anniversary, NFSU). Sony's CP firmware has a bug with that command stream; AMD's open-source cyan_skillfish2 CP microcode (same architecture) drops in as a replacement, confirmed at 60 CU / 2350 MHz / 17.9 TFLOPS.
- **PS5 Pro + M.2 NVMe: the write error that takes the filesystem read-only** has a workaround: add `mem=34G` to `cmdline.txt`. The NVMe's DMA mask is too wide for the Pro's memory layout; the proper kernel fix is coming.

## What to test
**D3D9 (Pro owners with the Viola firmware loaded):** a DXVK D3D9 game that hung at the first 3D frame. **M.2 NVMe:** a heavy write workload (kernel build, large file copy) with and without `mem=34G`. If you hit the M.2 error, `lspci -nn | grep 02.5` and paste it in the issue.

## Sharing logs
D3D9: `sudo dmesg | grep -E "ring|timeout|reset|gfx_0" | tail -10`. M.2: `sudo dmesg | grep -iE "I/O Error|nvme|TAbort|ext4.*emergency|journal.*abort" | tail -15`.
