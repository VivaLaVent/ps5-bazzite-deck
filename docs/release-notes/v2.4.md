## What's new

### bootc: the whole system as one image

Until now, PS5 Bazzite Deck has been updated the classic way: an update script replaces the kernel, drivers and settings file by file on the running system. That works, but every console ends up slightly different, and going back means undoing those files by hand.

Bazzite itself doesn't work that way. It's built as one complete system image, like an app container, and updated with **bootc**:

- **One image, built and checked as a whole.** The PS5 kernel, drivers and every PS5 fix are part of the image, built from this repository by GitHub Actions. Every bootc console runs exactly the same system.
- **Updates in the background.** `sudo bootc upgrade` downloads the new image while you play; it takes over at the next start. Nothing is half-installed if the power goes out.
- **One command back.** The previous image stays on the drive. `sudo bootc rollback` and a restart, and you're back where you were.
- **Your data stays.** Games, settings and your home folder live outside the image and are kept across updates and rollbacks.

v2.4 is the first release with a complete bootc image, plus the **bazzite-bootc-loader** that starts it: rmux's ps5-linux-loader built from source with patches for bootc's boot entries. It starts classic installs exactly as the standard loader does. bootc is experimental for now; classic installs keep updating the usual way.

### Wi-Fi and Bluetooth back to v2.1.1

Wi-Fi and Bluetooth problems on original PS5s started after v2.1.1. Every Bluetooth, Wi-Fi and restart script, service and rule changed since then is back to its v2.1.1 version, and releases v2.1.2 to v2.3 are withdrawn.

### A newer kernel

Linux 7.3.1 with rmux's current PS5 patches, the base most PS5 Linux images build on, and our own work on top:
- **Bluetooth:** newer fixes for the IW620 (original PS5) and MediaTek (Slim, Pro) chips, including one for the Bluetooth timeouts some of you saw
- **4K at 120 Hz** over HDMI 2.1 with automatic fallback when a TV or cable can't keep up, and ALLM (the TV's game mode switches on by itself)
- **RGB range** follows the display's standard "Broadcast RGB" setting
- **PS5 Pro:** CPU and GPU clock drivers with Pro limits
- **Still ours:** VRR on FLAVA3 consoles, the picture coming back after the TV wakes or switches input, keeping the display's details when it briefly reports garbage, the fixes for TVs that fall back to HDMI 1.4, the GPU temperature limit, overlay GPU load and temperature, suspend-to-idle

### Fixes

- **PS5 Pro: D3D9 games work.** Games like Fable Anniversary and NFS Underground hung at the first 3D frame.
- **PS5 Pro: 1 GB VRAM and an 80 °C GPU limit by default,** set once; your own changes stay.
- **The fan no longer spikes to full speed** at shutdown and reboot.
- **No 100 Hz test modes** any more; they caused picture artifacts on Verde consoles.
- **Safer updates:** the update refuses to run on a bootc install, and on an M.2 install it refuses a boot drive that belongs to another install.
- **`ps5-report`** now opens with a summary of your console (model, HDMI chip, wireless chip, install type) and collects everything a bug report needs.

### Changed defaults

Your display's own preferred mode is used instead of 1080p60. `hdmi.rgb_range` is gone; use the display's RGB setting.

## Already running

**Classic install:** update with the command under **Updating** below. If something is worse than before, go back with the undo command the update prints, and report it.

**bootc install:** `sudo bootc switch ghcr.io/vivalavent/ps5-bazzite-bootc:v2.4`, then restart.

## New install

Two ways in:

**Classic (recommended for most):** flash the full image from the [latest stable release](https://github.com/VivaLaVent/ps5-bazzite-deck/releases/latest), start it once, then update to v2.4 with the command under **Updating** above.

**bootc (experimental):** needs a drive of 64 GB or more (the system alone is about 25 GB).
1. Extract `ps5-bazzite-deck-bootc-v2.4.img.7z.001` with 7-Zip.
2. Flash the `.img`: on Windows with [Rufus](https://rufus.ie) in **DD mode** or [Balena Etcher](https://etcher.balena.io); on Linux or macOS with `sudo dd if=ps5-bazzite-deck-bootc-v2.4.img of=/dev/sdX bs=4M status=progress` (replace `/dev/sdX` with your drive).
3. Start it with `bazzite-bootc-loader-v2.4.elf`.

**First start, either way:** Steam downloads and updates itself before Game Mode appears. That can take 10 to 15 minutes, during which the screen stays black or shows the end of the boot text. Leave it running.

Report bootc results in `#bazzite-bootc-testing` on Discord.

## Known issues

- FLAVA3 consoles with an HDMI 2.1 TV: Game Mode stays black at 4K. Fixed in v2.4.1; until then, add `amdgpu.force_1080p=1` to `cmdline.txt`.

## What to test

- **bootc:** flash, start, Game Mode loads; `sudo bootc upgrade` and `sudo bootc rollback` work.
- **Original PS5 (IW620):** Wi-Fi and Bluetooth after a cold start, and pairing a DualSense.
- **FLAVA3 consoles with an HDMI VRR TV:** VRR in a game with Steam's VRR setting on; 4K at 120 Hz; the picture after the TV wakes or switches input.
- **Verde consoles:** picture at your usual resolution, after sleep and after switching between Game Mode and the desktop.
- **PS5 Pro:** a D3D9 game past its first 3D scene, GPU clock and temperature under load.

## Sharing logs

One command collects everything (Bluetooth, Wi-Fi, USB, display, GPU and, on bootc, the image status):
```
bash <(curl -fsSL https://raw.githubusercontent.com/VivaLaVent/ps5-bazzite-deck/main/tools/ps5-report.sh)
```
Paste its `SUMMARY` line when you report results, and attach the saved file for a bug report.
