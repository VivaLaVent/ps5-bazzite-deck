## What's new
> **Pre-release**, a quick package on top of v2.0.0 (kernel, Bluetooth driver and the changed scripts).

- **Fan as quiet as before v2.0.0 again:** the console's fan target is set to 80 °C at boot again, and the fan modes match upstream's, so fan tools (hwcon, CoolerControl) work as intended.
- **PS5 Pro: Bluetooth from a cold boot** (by mfoster978): no more dead adapter until a reload.
- **PS5 Pro: GPU load shows in overlays** (after mfoster978).
- **PS5 Pro: one DualSense for the PS5 system and Linux** (by mfoster978): the Linux-only Bluetooth address on the Pro too.
- **VRR back on TVs** that announce HDMI VRR with only a minimum refresh rate (a Panasonic OLED).
- **PS5 Pro firmware:** a clear message when the loader didn't dump it, and the README says which loader does.

## What to test
- **Fan (everyone):** idle and under load, as loud as on v1.8.x? `ps5-perf status` should say `fan control: console firmware (default)`.
- **PS5 Pro Bluetooth:** after a cold boot, `bluetoothctl list` shows a controller and a DualSense pairs without reloading anything.
- **VRR on a TV that lost it after v1.8.4:** Game Mode → Settings → Display → Enable VRR is there again.

## Sharing logs
Anything: `ps5-report`. Fan: `ps5-perf status` and `for h in /sys/class/hwmon/hwmon*; do [ "$(cat $h/name)" = ps5_fan ] && grep . $h/temp*_input $h/pwm1 $h/pwm1_enable; done`. Pro Bluetooth: `sudo dmesg | grep -iE "hci0|btusb|viola" | tail -20`. VRR: the display log from [docs/display-logs.md](https://github.com/VivaLaVent/ps5-bazzite-deck/blob/main/docs/display-logs.md).
