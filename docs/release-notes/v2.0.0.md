## What's new
> **Pre-release**, full image and update bundle, for every model. Everything since v1.8.4. Parts that nobody has tested yet are marked.

- **One DualSense for the PS5 system and Linux, on by default:** your controller keeps one pairing for the PS5 system and one for Linux (pair it with Linux once, on another profile, e.g. PS + Square). Fixed: on some consoles it needed pairing again after every cold boot (the address Linux used wasn't stable; it's saved now). *Needs confirming on the affected consoles.* On consoles with the IW620 chip, restarts go through the PS5 system instead of warm ones while this is on; `ps5-bt-address off` switches it off.
- **Better keyboard and controller reconnects on IW620 consoles** (from rmux's 7.3 port). *Untested on this image.*
- **PS5 Pro, two big ones:** (1) the Pro's own GPU firmware mostly never loaded in v1.8.0–v1.8.9 because of a 2-byte alignment bug in our initrd staging, so Pros ran as a base PS5 with 36 compute units; that's behind most of the Pro game crashes and HDMI losses reported. Fixed by mfoster978 (#27/#32). (2) Upstream's Pro work (#66) is ported in full: a GPU clock governor with a thermal limit, GPU busy reporting, the fan driver starting on the Pro. *Untested on this image so far: you're the first.* The Pro still needs a loader that dumps the firmware.
- **New fan driver:** a standard hwmon device with a fan curve. The console's own fan control stays the default; the curve is opt-in. `ps5-perf status` shows the mode and the fan speed.
- **Display, from the v1.8.5–v1.8.8 test kernels:** 4K120 only where the TV can take it, with automatic fallback to 4K; VRR only for displays with HDMI VRR (as on the PS5 system); 100 Hz modes; HDMI link settings sent at every mode change for TVs that dropped to HDMI 1.4 modes.
- **Smaller:** Logitech wheel force feedback, no failed services at boot, the updater removes old backups, `ps5-report` with a PS5 Pro section, the official wiki linked from the README.

## What to test
Every item says how to check it. Report what works too, with your console model (`ps5-report` tells you).

- **Controller (everyone):** pair with Linux once (on another profile than the PS5 system's, e.g. PS + Square), then switch PS5 system → Linux → PS5 system twice, and do one cold boot. It should connect every time without pairing again.
- **Bluetooth on IW620 consoles** (most original PS5s): keyboards and controllers should reconnect after being switched off and on. This uses a new reconnect fix; if Bluetooth is *worse* than on v1.8.9, say so, that's the change to look at.
- **GPU clock (everyone, new driver):** games should run as before. `cat /sys/class/devfreq/ps5-gpufreq/cur_freq` shows the clock (in Hz) while idle and in a game.
- **Fan:** `ps5-perf status` should say `fan control: console firmware (default)`, fan noise as before.
- **PS5 Pro:** after the second start with the loader, `ps5-report`'s PS5 Pro section should show 60 compute units and the Viola firmware loaded; play something that crashed before.
- **Display:** as before. Anything new: the display log below.

## Sharing logs
Post in [#bazzite-problems](https://discord.gg/ps5linux) or as a [GitHub issue](https://github.com/VivaLaVent/ps5-bazzite-deck/issues), and attach files rather than pasting them.

| Problem | What to send |
|---|---|
| Anything | `ps5-report` (in a terminal or over SSH; saves `ps5-report-*.txt` in your home folder) |
| Picture, modes, VRR, 4K120 | the display log from [docs/display-logs.md](https://wiki.ps5-linux.eu/troubleshooting/display-recovery#reporting-a-display-problem) |
| Bluetooth | before rebooting: `{ ps5-bt-address status; lsusb; journalctl -u ps5-bt-addr -u bluetooth -b --no-pager \| tail -40; sudo dmesg \| grep -iE "btusb\|btmtk\|hci0\|usb 5-" \| tail -30; } > ~/bt-log.txt 2>&1` |
| A game crashes | Steam launch options `PROTON_LOG=1 %command%`, play until it crashes, then send `~/steam-<appid>.log` and `sudo dmesg \| tail -80` |
| Black screen with "page fault" / "ring timeout" in dmesg | right after it happens: `sudo cp /sys/class/drm/card0/device/devcoredump/data ~/gpu-coredump.txt` |

No network? Copy the file to the drive's small FAT partition and take it from there on a PC: `E=$(for d in /boot/efi /efi; do sudo test -f $d/cmdline.txt && echo $d && break; done); sudo cp ~/ps5-report-*.txt $E/`.

## Known issues
- **PS5 Pro:** a first version. Not yet: the 40-CU unlock, the Linux-only Bluetooth address. Needs a loader that dumps the Pro's GPU firmware.
- **Game Mode's GPU fault when switching sessions at 4K120** on some TVs (a compositor-side bug; keep the desktop at 4K60 as a workaround).
- **VRR on monitors with only FreeSync** isn't supported (nor on the PS5 system).
- **VRR, 4K120 on consoles with the VERDE HDMI chip** aren't supported yet.
- **`Failed to pin framebuffer: -ENOMEM` and stutter under memory pressure** (issue #28): being investigated; raising ZRAM helped one reporter.
