## What's new

**Pre-release.** Test it on a second drive or with `sudo bootc switch ghcr.io/vivalavent/ps5-bazzite-bootc:beta`, and report back with `ps5-report`.

- **PS5 Pro: games that went black now run.** Since v2.1.6 the Pro used a substitute for part of its GPU firmware (to fix DXVK D3D9 games), and that substitute hung D3D12 games such as Dragon's Dogma 2 in a GPU reset that never recovered. The Pro uses Sony's own firmware again, as up to v2.1.1. A D3D9 game that hangs at its first frame: add `ps5.viola_cp=cs2` to `cmdline.txt` to bring the substitute back.
- **PS5 Pro: 60 compute units on more firmware versions.** bazzite-bootc-loader is now built from soniciso1's loader, which dumps the Pro's GPU firmware on 11.00 to 11.60, 12.00, 12.02, 12.40, 12.70 and 13.20 to 13.60. Use the loader from this release.
- **Quieter, calmer fan:** the console's own fan control with an 80 °C target is the default again, as in v1.8.9 (also during sleep and shutdown). The hwcon plugin and app still switch to a fan curve.
- **100 Hz modes** (1080p, 1440p and 4K at 100 Hz on consoles with the FLAVA3 HDMI chip) are back as an option: add `hdmi.modes_100hz=1` to `cmdline.txt`.
- **Bluetooth on most Slims** survives a warm reboot, and keeps its Linux-only address when the adapter is slow to come up at start (the DualSense couldn't connect then).
- **PS5 Pro: faster AI upscaling.** The bootc image's Vulkan driver (RADV) now uses the Pro's int8 matrix instructions and its compute queue (Borchev's Mesa patch): FSR4's INT8 model runs about 3.6 times faster, which kept Dragon's Dogma 2 at 60 FPS with FSR4 frame generation. Base PS5s and Slims behave as before. `RADV_VIOLA_ML=0` in a game's launch options turns the new instructions off.
- **6 GB VRAM by default** on every console, new installs and existing ones (once; `vram.txt` on the boot partition changes it).
- **Starts in Desktop Mode.** New and existing installs start in the KDE desktop from now on. To start in Game Mode again, change the default session in Steam's settings in Game Mode.
- **Steam's own startup and suspend videos** instead of Bazzite's; videos you added yourself stay. New installs also keep Steam's own branding.
- **Steam works the same in Desktop Mode and Game Mode again.** v2.5.1 broke part of Bazzite's own setup (Steam's update branch in Desktop Mode, the Return to Game Mode shortcut).
- **Update channels:** Stable gets the stable release's kernel, Beta the newest pre-release's.
- **`ps5-m2-install` fixed:** the copy step failed on every console; it now shows progress and checks that the system really starts from the M.2.
- **Legacy installs** started from an M.2 or another drive update in place again (the update refused with "this is not a PS5 Bazzite Deck install").

## bootc

### New install, or switching from Legacy

Switching means flashing the bootc image, which erases the drive: use a second drive, or copy off what you want to keep first. You need a USB drive or SSD of 64 GB or more.

1. Extract `ps5-bazzite-deck-bootc-v2.6.1.img.7z.001` with [7-Zip](https://www.7-zip.org) (not Windows' built-in extraction). The first line of `ps5-bazzite-deck-bootc-v2.6.1.sha256` is the `.img`'s checksum; on Windows, `certutil -hashfile ps5-bazzite-deck-bootc-v2.6.1.img SHA256` shows yours.
2. Flash the `.img` with [balenaEtcher](https://etcher.balena.io) (drives flashed with Rufus stopped in an emergency shell for several users; balenaEtcher fixed it). When Windows offers to format the drive afterwards, choose **Cancel**. On Linux with `sudo dd if=ps5-bazzite-deck-bootc-v2.6.1.img of=/dev/sdX bs=4M status=progress conv=fsync` (replace `/dev/sdX` with your drive).
3. Start it with `bazzite-bootc-loader-v2.6.1.elf`.

The first start takes a few minutes. A PS5 Pro reaches 60 compute units from the second start, once the loader has dumped its GPU firmware.

### Updating

On v2.5.1: switch to the Beta channel (**Settings → System → OS Update Channel**), or run `sudo bootc switch ghcr.io/vivalavent/ps5-bazzite-bootc:beta`. On v2.5: first run the three lines from the [v2.5.1 notes](https://github.com/VivaLaVent/ps5-bazzite-deck/releases/tag/v2.5.1) once, then use the `bootc switch` command (v2.5's channel menu switches to Bazzite's own images). Restart, start with **this release's loader**, and start once more on a PS5 Pro.

## Problems

- `sudo bootc rollback`, then power off (not restart) and start with the loader.
- If a new version doesn't start at all: `ROLLBACK.txt` on the drive's boot partition explains how to start the previous one from a PC.
- Report it in Discord with the file `ps5-report` saves.

## Sharing logs

```
bash <(curl -fsSL https://raw.githubusercontent.com/VivaLaVent/ps5-bazzite-deck/main/tools/ps5-report.sh)
```
Paste its `SUMMARY` line when you report results, and attach the saved file for a bug report.

## Legacy

Installs from before v2.5 run the older Legacy form and update in place:
```
bash <(curl -fsSL https://raw.githubusercontent.com/VivaLaVent/ps5-bazzite-deck/main/tools/update-latest.sh) v2.6.1
```
Then power off and start with the loader. Switching to bootc is recommended (see bootc above).
