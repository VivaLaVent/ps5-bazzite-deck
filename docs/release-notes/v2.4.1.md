## What's new

### The picture is back at 4K

On FLAVA3 consoles with an HDMI 2.1 TV, v2.4 started Game Mode on a black screen at 4K. v2.4 had moved to a newer kernel base whose 4K handling stays black there, while our own display code, the one v2.1.x used, shows 4K60 and 4K120 on the same TV. v2.4.1 goes back to that proven base and keeps everything else from v2.4: the bootc image and loader, the Wi-Fi and Bluetooth scripts as in v2.1.1, the PS5 Pro and fan fixes.

If you added `amdgpu.force_1080p=1` or `hdmi.frl_4k120=0` to `cmdline.txt` to get a picture on v2.4, remove it after updating.

### Also

- **Updating to a new kernel works.** v2.4's update stopped with "running kernel 7.3.0, this bundle is for 7.3.1"; it now installs a new kernel next to the running one, which stays as the backup.
- **`ps5-report`** reads the kernel log reliably, shows the Bluetooth address, and no longer swallows commands pasted after it.
- The kernel is now named after its base and this project, `7.3.0-viva`.

The newer kernel base (7.3.1) comes back once it has been tested on FLAVA3, Verde and PS5 Pro consoles.

## Already running

**Classic install:** update with the command under **Updating** below.

**bootc install:** `sudo bootc switch ghcr.io/vivalavent/ps5-bazzite-bootc:v2.4.1`, then restart.

## New install

**Classic (recommended for most):** flash the full image from the [latest stable release](https://github.com/VivaLaVent/ps5-bazzite-deck/releases/latest), start it once, then update to v2.4.1 with the command under **Updating** above.

**bootc (experimental):** needs a drive of 64 GB or more.
1. Extract `ps5-bazzite-deck-bootc-v2.4.1.img.7z.001` with 7-Zip.
2. Flash the `.img`: on Windows with [Rufus](https://rufus.ie) in **DD mode** or [Balena Etcher](https://etcher.balena.io); on Linux or macOS with `sudo dd if=ps5-bazzite-deck-bootc-v2.4.1.img of=/dev/sdX bs=4M status=progress` (replace `/dev/sdX` with your drive).
3. Start it with `bazzite-bootc-loader-v2.4.1.elf`.

**First start, either way:** Steam downloads and updates itself before Game Mode appears, which can take 10 to 15 minutes on a black screen. Leave it running.

## What to test

- **FLAVA3 consoles:** Game Mode at your TV's native resolution, 4K60 and 4K120 where the TV supports them.
- **Original PS5:** Wi-Fi and Bluetooth after a cold start.
- **Updating from v2.4:** the update runs through, and `uname -r` shows `7.3.0-viva` after the restart.
