## What's new

### Wi-Fi and Bluetooth back to v2.1.1

Wi-Fi and Bluetooth problems on original PS5s started after v2.1.1. Every Bluetooth, Wi-Fi and restart script, service and rule changed since then is back to its v2.1.1 version, and releases v2.1.2 to v2.2 are withdrawn. The kernel's Wi-Fi and Bluetooth parts were already the same as in v2.1.1.

### A new way to keep Linux up to date on the PS5

v2.3 ships the first **bootc image**: an image-based version of the same system, built the way Bazzite itself is built. An update downloads a complete new image in the background and takes effect at the next start; if something goes wrong, one command puts the previous image back. The PS5 kernel and all PS5-specific scripts are part of the image.

The **bazzite-bootc-loader** ships with every release, built from source: rmux's ps5-linux-loader plus patches that teach it the boot entries bootc writes, the basis for automatic fallback in a coming release. It starts existing installs exactly as the standard loader does.

Everything in this release, the kernel included, is built by GitHub Actions from the repository.

### Also in this release

- **PS5 Pro: D3D9 games work.** DXVK D3D9 games hung at the first 3D frame; the fix that swaps in AMD's command-processor microcode now finds Bazzite's compressed firmware.
- **PS5 Pro: 1 GB VRAM and an 80 °C GPU limit by default,** set once; your own changes stay.
- **The fan no longer spikes to full speed at shutdown or reboot.**

## Trying the bootc image

The bootc image is experimental, and trying it means reflashing.

1. Extract `ps5-bazzite-deck-bootc-v2.3.img.7z.001` with 7-Zip.
2. Flash the `.img`:
   - **Windows:** [Rufus](https://rufus.ie) in **DD mode**, or [Balena Etcher](https://etcher.balena.io)
   - **Linux / macOS:** `sudo dd if=ps5-bazzite-deck-bootc-v2.3.img of=/dev/sdX bs=4M status=progress` (replace `/dev/sdX` with your drive)
3. Start it with `bazzite-bootc-loader-v2.3.elf`.

From then on: `sudo bootc upgrade`, and the new image is used from the next start. To go back: `sudo bootc rollback`, then restart.

**First start:** Steam downloads and updates itself before Game Mode appears. That can take 10 to 15 minutes, during which the screen stays black or shows the end of the boot text. Leave it running.

Report bootc results in `#bazzite-bootc-testing` on Discord.

## What to test

- **Original PS5:** Wi-Fi and Bluetooth after a cold start, and a DualSense pairing, as on v2.1.1.
- **PS5 Pro:** a D3D9 game past its first 3D scene; `cat /efi/vram.txt` shows `0x40000000`.
- **bootc:** flash, start, Steam Gaming Mode loads; `sudo bootc status` shows the booted image.
