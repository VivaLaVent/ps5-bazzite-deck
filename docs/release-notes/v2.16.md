## What's new

Pre-release on top of [v2.15](https://github.com/VivaLaVent/ps5-bazzite-deck/releases/tag/v2.15).

- **Drivers for controllers, wheels and streaming**, which Bazzite has and our kernel lacked: the Xbox Wireless Adapter (xone), Xbox controllers over Bluetooth (xpadneo, not in Bazzite), Logitech, Thrustmaster and Fanatec wheels with force feedback, the GameCube adapter, the OBS virtual camera (v4l2loopback) and Razer devices (openrazer). Logitech wheels most likely had no driver before.
- **Native resolution at the first start** (4K, 1440p or 1080p, at 60 Hz) instead of 1080p60. A resolution you chose stays. On a 4K TV games then render at 4K; choose 1080p under Settings → Display for higher frame rates. If the screen stays dark: `amdgpu.force_1080p=1` in `cmdline.txt` on the boot partition.
- **One DualSense pairing for the PS5 and Linux, on every console.** Pair in the PS5 OS; Linux imports the pairing at every start. The Linux-only Bluetooth address is gone. If you used it (original PS5, Pro): switch the controller to its PS5 profile; devices paired only in Linux need pairing again. *Withdrawn in v2.16.1 for the original PS5 and the Pro: on a Pro the imported pairing didn't connect ([#73](https://github.com/VivaLaVent/ps5-bazzite-deck/issues/73)).*
- **A GPU hang no longer freezes the display** (from the official PS5 kernel). The game may still close.
- **PS5 Pro:** 60 compute units on system software 13.00 (needs this release's loader); the GPU slows down at 85 °C instead of 80 °C.
- **Wi-Fi (original PS5)** no longer follows the access point's country.
- `ps5-report` shows Bazzite's package versions.

## What to test

- A game that froze the screen: does the desktop come back? `sudo dmesg | grep -iE "ring .* reset|recovery disabled|Recovery Failed"`
- Controllers, wheels, Razer devices, the Xbox adapter: do they work, with rumble or force feedback? `lsmod | grep -iE "xone|xpadneo|logitech|tmff|t150|fanatec|razer"`. Xbox controllers over Bluetooth: does Steam Input still work?
- Original PS5 and Pro: does the DualSense connect in Linux on its PS5 profile? `journalctl -b -u ps5-bt-import -o cat`
- A new install or a new display: does it start at native resolution?
- PS5 Pro on 13.00: `ps5-report` shows `compute units: 60`.
- A game dropping out of Game Mode with `Failed to pin framebuffer`: try it with Game Mode's **Force Composite** (see v2.16.1). **Don't use `amdgpu.sg_display=1`:** an earlier version of these notes suggested it for a VRAM test; on the PS5 it stops the console from starting. The test is removed in v2.16.1.
- Wi-Fi drops to 0: at that moment, `iw dev wlp64s0f7 get power_save`.

## bootc

### New install

A USB drive or SSD of 64 GB or more; flashing erases it.

1. Extract `ps5-bazzite-deck-bootc-v2.16.img.7z.001` with [7-Zip](https://www.7-zip.org). The first line of `ps5-bazzite-deck-bootc-v2.16.img.sha256` is the image's SHA-256.
2. Flash the `.img` with [balenaEtcher](https://etcher.balena.io), not Rufus. If Windows offers to format the drive, choose **Cancel**.
3. Start it with `bazzite-bootc-loader-v2.16.elf`. The first start takes a few minutes.

### Switching from Legacy

In place, keeping users, games and Flatpaks: [wiki](https://wiki.ps5-linux.eu/updating/legacy). Or flash a new install.

### Updating

This pre-release is on the **Beta** channel: `sudo bootc switch ghcr.io/vivalavent/ps5-bazzite-bootc:beta`, or `sudo bootc upgrade` if you are on Beta already. Then start with the loader. A PS5 Pro on 13.00 needs `bazzite-bootc-loader-v2.16.elf`.

Back to Stable: the same `bootc switch` with `:stable`, or Steam → Settings → System → OS Update Channel.

## Problems

- `sudo bootc rollback`, then restart with the loader.
- It doesn't start at all: follow `ROLLBACK.txt` on the drive's boot partition.
- Report it on Discord with the file `ps5-report` saves.

## Known issues

- Bazzite's performance profile can't start the LAVD scheduler: our kernel is built with pahole 1.30. The rest of the profile works.
- Games dropping out of Game Mode with `Failed to pin framebuffer`: VRAM is full. See *What to test*; 6 GB VRAM (the default) or 5 GB is the safe setting.
- The clock is wrong for the first minute after a start, until network time arrives.
- Starting without the USB drive is experimental: [wiki](https://wiki.ps5-linux.eu/installation/m2-bazzite-deck#usb-free).
- PS5 Pro: the CPU stays at 3.2 GHz.
- VERDE HDMI chip: no HDR.
- M.2 installs from v2.11 or older can stop in an emergency shell after an update: [fix](https://wiki.ps5-linux.eu/troubleshooting/error-messages#ostree-boot-counter).
- A drive flashed before v2.11 doesn't start on PS5 system software 4.x: [fix](https://wiki.ps5-linux.eu/troubleshooting/error-messages#gpt-first-lba).
