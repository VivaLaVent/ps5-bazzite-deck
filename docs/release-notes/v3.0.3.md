## What's new

Pre-release on top of [v3.0.2](https://github.com/VivaLaVent/ps5-bazzite-deck/releases/tag/v3.0.2).

- **v3.0.2's VRAM floor now actually reaches Game Mode.** In v3.0.2 it only got as far as the top level: `ps5-report` showed `session not running` even while Game Mode ran. Found by Max, who also confirmed his five games now start (3 of 3 each, 4 GB VRAM). `ps5-report` should now show `VRAM floor for Game Mode: system 512 MiB, session 512 MiB` in Game Mode.
- **A kernel switch to test against games dropping out of Game Mode** (`Failed to pin framebuffer`), off by default. v3.0.2's VRAM floor lets such games start, but the drop can still happen after the Steam overlay or the Quick Access Menu has been opened several times (thanks, Delta). `amdgpu.ps5_scanout_reserve` keeps part of VRAM for the picture itself: games are turned away from it, so a new overlay finds room even when a game has filled the rest. It changes nothing until you switch it on.

## What to test

- In Game Mode, `ps5-report` (GPU section): both values 512 MiB? If not, please post `for d in /sys/fs/cgroup/user.slice /sys/fs/cgroup/user.slice/user-1000.slice /sys/fs/cgroup/user.slice/user-1000.slice/user@1000.service; do echo "$d: $(cat $d/dmem.min 2>&1)"; done`.
- A game that drops out of Game Mode after opening the Steam overlay (PS button) a few times. Switch the reserve on for this session: `echo 512 | sudo tee /sys/module/amdgpu/parameters/ps5_scanout_reserve`, then start the game again. To keep it across restarts: `sudo rpm-ostree kargs --append=amdgpu.ps5_scanout_reserve=512`, then restart with the loader.
- Tell us the game, the value (256, 512 or 1024) and whether the drops stop. `ps5-report` shows the value in its GPU section. `0` switches it off again.
- Keep VRAM at 4 GB or more.

## bootc

### New install

A USB drive or SSD of 64 GB or more; flashing erases it.

1. Extract `ps5-bazzite-deck-bootc-v3.0.3.img.7z.001` with [7-Zip](https://www.7-zip.org). The first line of `ps5-bazzite-deck-bootc-v3.0.3.img.sha256` is the image's SHA-256.
2. Flash the `.img` with [balenaEtcher](https://etcher.balena.io), not Rufus. If Windows offers to format the drive, choose **Cancel**.
3. Start it with `bazzite-bootc-loader-v3.0.3.elf`. The first start takes a few minutes.

### Switching from Legacy

Flash a new install, or convert in place with the converter from v2.16.2, keeping users, games and Flatpaks: [wiki](https://wiki.ps5-linux.eu/updating/legacy).

### Updating

`sudo bootc upgrade`, or Steam's update button. It applies at the next start with the loader. Use `bazzite-bootc-loader-v3.0.3.elf` from this release: a PS5 Pro on system software 13.00 needs it for its GPU.

Stable follows the release marked **Latest**, Beta the newest pre-release: `sudo bootc switch ghcr.io/vivalavent/ps5-bazzite-bootc:beta` (or `:stable`), or Steam → Settings → System → OS Update Channel.

## Problems

- `sudo bootc rollback`, then restart with the loader.
- It doesn't start at all: follow `ROLLBACK.txt` on the drive's boot partition.
- Report it on Discord with the file `ps5-report` saves.

## Known issues

- PS5 Pro: a DualSense paired in the PS5 OS doesn't connect in Linux ([#73](https://github.com/VivaLaVent/ps5-bazzite-deck/issues/73)); the Pro keeps its own Linux Bluetooth address, pair once in Game Mode.
- DualSense over Bluetooth, late or ghost inputs in a Proton game: Bazzite Portal → Troubleshoot → switch InputPlumber off.
- Some games drop out of Game Mode with `Failed to pin framebuffer` when VRAM is full: Rift Apart runs with Steam's Force Composite (see Option in What's new); Returnal, Avowed and Spider-Man: Miles Morales still need Desktop Mode.
- VERDE HDMI chip: no VRR yet.
- The clock is wrong for the first minute after a start, until network time arrives.
- Starting without the USB drive is experimental: [wiki](https://wiki.ps5-linux.eu/installation/m2-bazzite-deck#usb-free).
- M.2 installs from v2.11 or older can stop in an emergency shell after an update: [fix](https://wiki.ps5-linux.eu/troubleshooting/error-messages#ostree-boot-counter).
- A drive flashed before v2.11 doesn't start on PS5 system software 4.x: [fix](https://wiki.ps5-linux.eu/troubleshooting/error-messages#gpt-first-lba).
