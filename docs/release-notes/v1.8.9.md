## What's new
> **Previous stable version, Legacy install only.** The current version is [v2.5](https://github.com/VivaLaVent/ps5-bazzite-deck/releases/tag/v2.5), built with bootc, and switching to it is recommended. Come back here only if v2.5 gives a Legacy install trouble: run the update command below, or flash this image.

- **One DualSense for the PS5 and Linux, on by default:** Linux has its own Bluetooth address on every console, so your controller keeps a pairing for the PS5 system and one for Linux (pair it with Linux once, on another profile, e.g. PS + Square). On consoles with the IW620 chip, restarts then go through the PS5 system instead of warm ones; `ps5-bt-address off` switches it off.
- **MediaTek (Slim):** where setting that address didn't work, MediaTek's own command is used now.
- **Everything from the v1.8.5–v1.8.8 test kernels:** 4K120 only where the TV can take it (and back to 4K by itself if the link fails), VRR only for displays with HDMI VRR, 100 Hz modes, the HDMI 2.x link settings at every mode change.
- **Cleanups:** no failed services at boot, Logitech wheel force feedback, `hdmi.rearm=0` removed from `cmdline.txt`.

## Testing
Pair your controller with Linux once (on another profile than the PS5 system's), then switch between the PS5 system and Linux a few times: it should connect on both without pairing again. `ps5-bt-address status` shows the address.
