## What's new
> **TEST BUILD.** For testing 100 Hz modes; everyone else stays on the release marked **Latest**.

- **100 Hz modes** on consoles with the FLAVA3 HDMI chip, shown only when your display goes to 100 Hz or more:
  - **1440p100:** most likely works (the HDMI chip already handles 1440p60 and 1440p120 the same way).
  - **1080p100:** unknown; that's what this test is for. If it gives no picture, see the recovery guide below.
  - **4K100:** only if your TV lists it; it uses the same link as 4K120 and falls back to 4K by itself if the link doesn't come up.

## Testing
For each 100 Hz mode your display offers (Game Mode → Settings → Display): picture or not, and with VRR on and off. Post your display model and `sudo dmesg | grep -i -e "hdmi" | tail -20` in #bazzite-prereleases-experimental. No picture: [docs/display-recovery.md](https://wiki.ps5-linux.eu/troubleshooting/display-recovery).

## Known issues
- A 100 Hz mode the HDMI chip can't do gives a black screen until you switch back (1080p100 is the uncertain one).
