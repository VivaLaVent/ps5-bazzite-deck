## What's new
- **Fix: Bluetooth adapter went away after boot on original PS5s (IW620)**: the Linux-only address script re-initialised the adapter to make the kernel pick up the new address, but then sent the retry command before the chip was ready. It timed out, and the adapter vanished. It now waits before checking and before the retry.

## What to test
Original PS5 (IW620), cold boot: `ps5-report | head -12` shows `linux-only BT address: on, applied`, and the DualSense connects without a hang.
