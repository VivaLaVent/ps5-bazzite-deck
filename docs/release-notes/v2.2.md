## What's new in v2.2

### A new way to keep Linux up to date on the PS5

Until now, updating meant running a script that replaced individual files. Rolling back meant installing a previous kernel update, which worked but left you managing versions manually.

v2.2 ships the first **bootc image**: an atomic, image-based version of the same system, built the way Bazzite itself is built. An update pulls a complete new image in the background. If something goes wrong, one command puts the previous image back and a restart applies it. No reflashing, no manual version management. The PS5 kernel and all the PS5-specific scripts are part of the image, so a single update command keeps everything in sync.

The **PS5 loader** now ships with every release, built fresh from source. This is what makes the bootc image work properly: the loader reads the bootc image's boot entries, selects the right deployment on each start, counts boot attempts and can fall back to the previous deployment automatically. Without a matching loader the bootc rollback guarantee does not hold. Previously the loader was a separate download with no version tie to the image.

**Bluetooth fix (all installs, IW620 chip):** the address script was being launched twice by udev at boot. The re-init triggered a second copy, the two copies fought over the chip, and the adapter disappeared. A lock now prevents the second copy from running.

## Already running PS5 Bazzite Deck

On the PS5, in a terminal or over SSH:

```
cd ~ && rm -rf ps5-quick-v2.2* && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v2.2/ps5-quick-v2.2.tar.gz && tar xzf ps5-quick-v2.2.tar.gz && bash ps5-quick-v2.2/install.sh
```

**What to test:** cold boot, then `ps5-report | head -12`. It should show `linux-only BT address: on, applied`. Bluetooth scan and DualSense pairing should work without crashing Wi-Fi.

**Sharing logs:** `journalctl -u ps5-bt-addr -b --no-pager | tail -10`

## Trying the bootc image

The bootc image is experimental. You have to reflash to try it; existing installs are not migrated automatically.

Flash the `ps5-bazzite-deck-bootc-v2.2.img` disk image to a USB drive or SSD.

- **Linux / macOS:** `sudo dd if=ps5-bazzite-deck-bootc-v2.2.img of=/dev/sdX bs=4M status=progress` (replace `/dev/sdX` with your drive)
- **Windows:** use [Rufus](https://rufus.ie) in **DD mode** (not ISO mode), or [Balena Etcher](https://etcher.balena.io)

Once booted, the entire update process is:

```
sudo bootc upgrade
```

The new image downloads in the background and takes effect at the next restart. To go back to the previous image:

```
sudo bootc rollback
```

**What to test:**
- Flash, boot, Steam Gaming Mode loads.
- `sudo bootc status` shows the booted image and the staged update.
- `ps5-report | head -15` covering Wi-Fi, Bluetooth, fan and GPU.
- `sudo bootc upgrade` stages the latest image for the next boot without interrupting the current session.

**Known issues in v2.2:** Wi-Fi may not come up on the very first boot if the firmware was not staged. A second boot fixes it.

Report bootc issues in `#bazzite-bootc-testing` on Discord, not in `#bazzite-problems`.
