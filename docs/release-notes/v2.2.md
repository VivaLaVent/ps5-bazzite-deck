## What's new

This is the first release built from the unified repo: the **PS5 loader**, the **bootc image** and the **classic update bundle** all ship from one tag.

**PS5 loader:** built from [rmux's ps5-linux-loader](https://github.com/ps5-linux/ps5-linux-loader) at `940bce3` + BLS patches, attached to every release as `ps5-linux-loader-v2.2.elf`. SHA-256 is in the release notes.

**Bootc image (experimental):** `sudo bootc upgrade` on a running bootc install, or reflash from the new disk image. Known issues: Wi-Fi firmware may not be staged when two Linux drives are plugged in simultaneously — use the bootc drive only for now. Root resize and composefs are fixed in this build. Report bootc issues in `#bazzite-testing` on Discord.

**Classic update (non-bootc):** installs over any 2.x release with the usual update command. No kernel change from v2.1.6.

- **Fix: Bluetooth adapter gone after boot on original PS5s (IW620).** `btmgmt power on` during the re-init fires a second udev event, launching a second copy of the address script. The two copies fought over the chip with a double power-cycle; the chip stopped responding and the adapter disappeared. A lock prevents the second copy from running.

## What to test

- **IW620 (original PS5), cold boot:** `ps5-report | head -12` shows `linux-only BT address: on, applied`. Bluetooth scan and DualSense pairing work.
- **Bootc:** flash the disk image with dd, `sudo bootc upgrade` works, Wi-Fi comes up (single drive only), Steam Gaming Mode loads.
- **Loader:** the ELF attached to this release boots Linux on firmware 3.00–13.60.

## Sharing logs

Bluetooth: `journalctl -u ps5-bt-addr -b --no-pager | tail -10`
Bootc: `sudo bootc status` and `ps5-report | head -15`
