## What's new

This is the first release built from the unified repo: the **PS5 loader**, the **bootc image** and the **classic update bundle** all ship from one tag.

**Bootc image (experimental):** `sudo bootc upgrade` on a running bootc install, or reflash from the new disk image. Known issues: Wi-Fi firmware may not be staged when two Linux drives are plugged in simultaneously (use the bootc drive only). Root resize and composefs are fixed. Report bootc issues in the testing channel on Discord.

- **Root-cause fix for Bluetooth adapter disappearing on original PS5s (IW620).** The re-init that makes the kernel pick up the new address fires a second copy of the address script via udev. The two copies fought over the chip, causing a double power-cycle that the chip couldn't recover from. A lock now prevents the second copy from running.

## What to test
Original PS5 (IW620), cold boot: `ps5-report | head -12` shows `linux-only BT address: on, applied`. Bluetooth scan and DualSense pairing work without crashing Wi-Fi.
