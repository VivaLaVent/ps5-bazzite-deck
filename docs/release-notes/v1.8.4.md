## What's new
Everything since v1.7.2, for every model:
- **VRR flickers less:** the refresh rate never drops below 48 Hz, the PS5 system's own floor; below 48 fps frames are doubled at 120 Hz modes, 60 Hz modes keep a fixed 60 Hz. Many OLEDs flickered at the 40 Hz many TVs allow (suggested by hsgodd).
- **PS5 Pro support (first version):** the Pro's GPU with its 64 compute units, and its own GPU firmware: the loader puts it on the boot partition and the first boot adds it; start Linux with the loader once more to use it. Internal Bluetooth and Wi-Fi work. The CPU and GPU clocks stay with the Pro's firmware. Thanks to Borchev (GPU, upstream), QuartConz (Bluetooth) and the Pro testers.
- **Cleanups:** no more failed services at boot (Bazzite's `bootloader-update` and `greenboot` are only for its own installs); the update removes a leftover `hdmi.rearm=0` from `cmdline.txt`, and on IW620 consoles switches the Linux-only Bluetooth address off (it left Wi-Fi and Bluetooth hung after warm restarts).
- The display works as in v1.7.2/v1.7.3: VRR, 4K120 and HDR unchanged. (The display changes tried in the v1.8.1–v1.8.3 test builds were undone.)

## Known issues
- **PS5 Pro:** the first version; tell us in #bazzite-ps5-pro-tests what works and what doesn't.
- **4K120 gives no picture on some TVs** while it works on others. If it happens: [docs/display-recovery.md](https://wiki.ps5-linux.eu/troubleshooting/display-recovery).
- **VRR and 4K120 on consoles with the VERDE HDMI chip** aren't supported yet, so they aren't offered there.
- **GPU page faults when Game Mode starts** (coming from the desktop): the screen can freeze for a while. Being investigated.
- **Sleep uses a lot of power** (the GPU stays on). For longer breaks, power off.
