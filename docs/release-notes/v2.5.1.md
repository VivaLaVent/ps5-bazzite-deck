## What's new

**bootc consoles on v2.5: run this once before updating.** On v2.5, every update and channel switch fails with "Failed to start ostree-finalize-staged.service" (a mistake in v2.5's image). Run these three lines on the PS5, in a terminal or over SSH (password `ps5`); it should print `ready to update`. The change stays through all later updates.

```bash
sudo rm -f /etc/systemd/system/greenboot-set-rollback-trigger.service
printf '[Unit]\nDescription=No greenboot rollbacks on the PS5\n\n[Service]\nType=oneshot\nExecStart=/usr/bin/true\nRemainAfterExit=yes\n' | sudo tee /etc/systemd/system/greenboot-set-rollback-trigger.service >/dev/null
sudo systemctl daemon-reload && sudo systemctl start ostree-finalize-staged.service && echo "ready to update"
```

**PS5 Bazzite Deck is a bootc image now, and that is the way to run it.** Still on an older Legacy install? Switching is recommended, see bootc below. Not sure which one you run? `ps5-report` shows it on its Install line.

- **Steam's OS update channel works.** It lists **Stable** and **Beta**, both of PS5 Bazzite Deck. On v2.5, picking a channel there switched to Bazzite's own images, which can't start on a PS5: leave it alone until you're on v2.5.1.
- **Weekly updates reach every bootc console.** Consoles installed from v2.5's image stayed on v2.5 for good; v2.5.1 moves them to the Stable channel by itself.
- **PS5 Pro: Bluetooth works again,** from a cold boot and after sleep, as in v2.1.x.
- **PS5 Pro: cooler and quieter.** Its power controller never answers CPU clock requests; the waiting then blocked the GPU's clock control too, so the GPU couldn't slow down at idle. The Pro's CPU clock is left to its firmware again, as in v2.1.x, and the red `mp1` errors at startup are gone.
- The login banner now names this image instead of Bazzite's.
- **The system can move to the M.2,** bootc and Legacy alike, with a new script that copies the running system to the console's M.2 drive and starts it from there. The USB drive stays plugged in. Steps on the [wiki](https://wiki.ps5-linux.eu/installation/m2-install#ps5-bazzite-deck).

## bootc

PS5 Bazzite Deck is a bootc image: the whole system is one image, built and checked as a unit by GitHub Actions, the way Bazzite itself is made.

- **Every console runs the same system.** The PS5 kernel, drivers and fixes are part of the image, not files changed on your drive.
- **Updates download in the background** and take over at the next start. A power cut during an update doesn't leave a half-installed system.
- **The previous version stays on the drive.** `sudo bootc rollback`, then power off and start with the loader, takes you back.
- **Games, settings and your files are kept** across updates and rollbacks.

It starts with **bazzite-bootc-loader** from this release: the official Linux loader built from its `main` branch, plus support for the boot entries bootc uses to choose and roll back versions.

### New install, or switching from Legacy

Switching means flashing the bootc image, which erases the drive: use a second drive, or copy off what you want to keep first. You need a USB drive or SSD of 64 GB or more.

1. Extract `ps5-bazzite-deck-bootc-v2.5.1.img.7z.001` with 7-Zip.
2. Flash the `.img`: on Windows with [Rufus](https://rufus.ie) in **DD Image mode** (balenaEtcher has produced drives that don't boot); on Linux or macOS with `sudo dd if=ps5-bazzite-deck-bootc-v2.5.1.img of=/dev/sdX bs=4M status=progress` (replace `/dev/sdX` with your drive).
3. Start it with `bazzite-bootc-loader-v2.5.1.elf`.

On the first start, Steam downloads and updates itself before Game Mode appears. That can take 10 to 15 minutes on a black screen; leave it running.

### Updating

**On v2.5, first run the three lines at the top of these notes,** once; without them the update fails with "Failed to start ostree-finalize-staged.service". Then: Steam's update button (**Settings → System**) or `sudo bootc upgrade`, once v2.5.1 is marked stable. To try it before that: `sudo bootc switch ghcr.io/vivalavent/ps5-bazzite-bootc:v2.5.1`. After an update, restart and start with the loader.

From v2.5.1 on, **Settings → System → OS Update Channel** offers **Stable** and **Beta**, both of PS5 Bazzite Deck. Beta gets the same as Stable for now; later it gets the newest test kernel and the next Bazzite version first.

## Problems

- `sudo bootc rollback`, then power off (not restart) and start with the loader.
- If a new version doesn't start at all: `ROLLBACK.txt` on the drive's boot partition explains how to start the previous one from a PC.
- On a Legacy install: the undo command the update prints, or go back to [v1.8.9](https://github.com/VivaLaVent/ps5-bazzite-deck/releases/tag/v1.8.9) with the update command and `v1.8.9`.
- Either way, report it in Discord with the file `ps5-report` saves.

## What to test

- **Update channel:** Settings → System → OS Update Channel shows only Stable and Beta; switch to Beta and back.
- **Rollback:** after an update, `sudo bootc rollback`, power off and the loader bring the previous version back; `bootc status` shows which one runs.
- **PS5 Pro:** Bluetooth after a cold boot and after sleep; temperature and fan at idle in Game Mode; no red `mp1` lines at startup.

## Legacy

Installs from before v2.5.1 run the older Legacy form and update in place:
```
bash <(curl -fsSL https://raw.githubusercontent.com/VivaLaVent/ps5-bazzite-deck/main/tools/update-latest.sh) v2.5.1
```
Then power off and start with the loader. Switching to bootc is recommended (see bootc above).
