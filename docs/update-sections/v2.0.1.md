## Updating
A quick update (kernel, Bluetooth driver and changed scripts) for consoles on **v2.0.0** (update to v2.0.0 first with the normal update command if you're on something older). On the PS5 (in a terminal or over SSH, password `ps5`), with a network connection:
```
cd ~ && rm -rf ps5-quick-v2.0.1* && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v2.0.1/ps5-quick-v2.0.1.tar.gz && tar xzf ps5-quick-v2.0.1.tar.gz && bash ps5-quick-v2.0.1/install.sh
```
It keeps a backup and prints an undo line. Then power off and start with the loader. `/etc/ps5-bazzite-deck-version` then says `v2.0.1 (quick kernel)`.
