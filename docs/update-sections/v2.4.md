## Updating
From v1.0.3 or newer, without reflashing. On the PS5 (in a terminal or over SSH, password `ps5`), with a network connection:
```
bash <(curl -fsSL https://raw.githubusercontent.com/VivaLaVent/ps5-bazzite-deck/main/tools/update-latest.sh) v2.4
```
It downloads v2.4, checks it, makes a backup, installs the new kernel, drivers and settings, and prints `DONE` plus an undo command. Then power off and start with the loader.

**From v1.0.2 or older:** reflash.
