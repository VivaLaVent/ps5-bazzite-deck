# PS5 Bazzite Deck

[Bazzite](https://bazzite.gg) in Steam Deck mode for the PlayStation 5. It runs from a USB drive or the M.2 slot and starts in the KDE desktop, with Game Mode one click away. The PS5's own system stays untouched.

Not affiliated with Bazzite, Universal Blue or Sony. Ask here or on Discord, not in Bazzite's channels.

## Updates

The system is one bootc image: `sudo bootc upgrade` updates it, `sudo bootc rollback` goes back. Steam's OS Update Channel switches between Stable and Beta. Start it with bazzite-bootc-loader from the same release. Details: [bootc/README.md](bootc/README.md).

Installs from before v2.5 (Legacy) are no longer updated: [switch to bootc](https://wiki.ps5-linux.eu/updating/legacy).
